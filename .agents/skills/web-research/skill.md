# Web Research

Use this skill when a task needs current, external, or source-attributed information. Web research is useful only when it improves accuracy; do not search merely to decorate an answer with links.

## Workflow

1. **Define the question.** Identify the claim, decision, or fact pattern the search must resolve. This keeps the research from drifting into background reading.
2. **Search with varied phrasing.** Use multiple `web_search` queries for different angles, names, dates, and source types. Do not stop at the first plausible result.
3. **Prefer primary sources.** Read official documentation, source repositories, standards, papers, release notes, original announcements, or primary data before relying on secondary summaries.
4. **Track dates.** For changing topics, record publication dates, version dates, or event dates. A correct old source can still be the wrong answer today.
5. **Cross-check important claims.** Confirm consequential facts against independent sources when possible. Note disagreements explicitly.

## Source Handling

Cite the URL for every non-obvious claim that affects the answer. Distinguish facts from inference. If a source is weak, old, ambiguous, or promotional, say so rather than treating it as equal evidence.

## Output Shape

End with a self-contained summary: the key findings, the strongest evidence, and any open questions that materially affect confidence. Do not return a pile of links without synthesis.
