What kind of change this entry makes to the ones it supersedes. Leave it empty when it supersedes nothing.

- `correction` — the earlier entry was wrong. What it asserted is not the case, and this states what is.
- `refinement` — the earlier entry was right but partial or imprecise. This says the same thing with what it was missing.
- `merge` — several entries said one thing between them. This is that one thing, naming all of them.
- `retraction` — the earlier entry no longer bears on the work: the question closed, the thread ended, the condition lifted. State what is now the case, not that the entry is being retired.

Pick the one that is true. A `correction` filed as a `refinement` tells the next reader the old entry can still be trusted.
