What kind of instruction this is.

- `requirement` — something that must be true of the work: a thing to build, a thing to change, a property it must have. Not the act of asking. A question whose answer was given in these same turns leaves no requirement behind, because there is nothing left that must hold.
- `preference` — how they want the work done: naming, structure, tone, tools, process. These govern work they have not seen yet, and they are the easiest to lose.

Whether an instruction corrects an earlier one is not a kind: name the earlier id in `supersedes` and set `revision` to `correction`. A redirected requirement is still a requirement.
