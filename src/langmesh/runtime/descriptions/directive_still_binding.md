Whether this instruction still governs the work. False only where a later message plainly lifted it.

Being satisfied is not being lifted: an instruction that has been carried out still binds, because it is why the work looks the way it does and the next model must not undo it.

Since nothing is ever edited, retiring an instruction means writing a new entry that restates it with this set to false, naming the old id in `supersedes` with `revision` set to `retraction`. Where they replaced it with something else instead, the new entry states that new instruction, this stays true, and the `revision` is a `correction`.
