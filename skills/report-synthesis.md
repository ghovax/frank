# Report synthesis

Use this skill when you must merge multiple inputs (research findings, sub-agent deliverables) into a single report.

1. **Read every input fully** before writing anything.
2. **Cross-reference.** Identify where inputs agree, disagree, or overlap. Surface contradictions explicitly rather than averaging them away.
3. **Structure for the reader.** Lead with the bottom line, then the supporting detail. Use headings and tables where they aid comparison.
4. **Synthesise, don't concatenate.** Add analysis and connections across the inputs; do not just paste each input in turn.
5. **Attribute** non-obvious claims to their source, and keep it self-contained — the report should stand on its own.
